# 🚀 KANJI STRIKER

> **Learn Japanese. Fight through the galaxy.**

**KANJI STRIKER** is a mobile-first Japanese Kanji learning arcade game built around a classic vertical 2D space shooter experience. It combines retro pixel-art arcade action with effective Japanese language learning (JLPT N5-N1 focus).

---

## ✨ Features

- **Arcade Shooter Gameplay:** Control your spaceship, dodge enemies, and shoot targets using smooth touch or mouse drag controls.
- **Integrated Japanese Learning:** Match Mongolian meanings with correct Kanji characters floating on enemy ships.
- **Mobile-First Design:** Optimized for portrait smartphone browsers with responsive Canvas rendering.
- **Zero Heavy Dependencies:** Built purely with **HTML5, CSS3, and Vanilla JavaScript (ES Modules)** — no complex frameworks, npm build tools, or external libraries required.
- **Retro Aesthetic:** Deep space backgrounds, vibrant neon neon-yellow typography, and classic arcade styling.
